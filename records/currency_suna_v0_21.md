# お金「時（SUNA）」と地域の通貨 v0.21（2026-10-25）

## 本人が決めたこと
- 世界でひとつの通貨「時（SUNA）」がある。Bitcoin と同じく、ただひとつのもの。
- Bitcoin と同じ原理で動く。
- ある社会で1時間働いて得られる普通の賃金を、1 SUNA の価値とする。この価値は地域ごとに違い、各地域が SUNA に書き込む（投稿する）。
- 各地域は、それぞれの通貨名を使う。地域の通貨を「〇〇SUNA」と呼ぶのは紛らわしいので禁止。

## Claude の仮の提案（変更可）
- 地域の通貨名は、漢字圏の5か国で昔から使われた単位から取る。
  - 二水・明山の通貨は「文（もん / Mun / Wén / Văn）」。
  - 改神国（白港）の通貨は「両（りょう / Ryang / Liǎng / Lạng）」。
- 二水では 1 SUNA＝1,200文。
- Bitcoin と同じ原理の意味は、次のとおり。
  - 中央の銀行を持たない。
  - みんなが同じ記録（帳簿）を持って、確かめ合う。
  - 一度書いた記録は書き換えられない。
- モールの値段は二水の「文」で付け、横に SUNA でいくらかも出す。
  - 焼き魚は 400文。
  - 学園の制服は 30,000文で、25 SUNA。
