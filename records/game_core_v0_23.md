# ゲームの芯（v0.23, 2026-10-25）

## ひびきさんが決めたこと
- ユーザーは、最初にログインしたとき、お金が0。
- ゲームでは、ユーザーがキャラになる。
- キャラとして社会を作ることができる。
- 大事なのは、ユーザーが一つの経済システムを回すこと。
- キャラの行動を予約できる。稼ぐ、休む、啓発（学ぶ・自分を高める）、遊ぶ、など。
- ステータスとして見えるのは RGB のステータス（HP・MP など）だけ。
- キャラは0歳で生まれ、時間とともに育つ。
- 最初は現実と同じで、意識ややりたいことを持てない。
- 自我が生まれてから、少しずつ選択肢と行動の自由が増える。
- ゲームの形はシンプルにする（トークンがかかりすぎないように）。

## 旧案との関係
- 旧案「遊ぶ人は名前のない声で、ささやくだけ。決めるのはキャラ」は、今回「ユーザーがキャラになる」に置きかえる。
- ただし幼いあいだは自由がないので、「声」は自我が生まれる前の時期の見せ方として残せる（案）。

## Claude の案（仮）
### RGB のステータス
| 色 | 中身 | 例 |
|---|---|---|
| R | 体（HP） | 働く・体を使うと減り、休むと戻る |
| G | 技（SP） | 作る・探す・稼ぐ力 |
| B | 心（MP） | 学ぶ・魔法・遊びで動く |
ほかの数値（スキル、好感度など）は裏で計算し、画面には出さない。

### 成長と自由の段階
| 年齢 | できること |
|---|---|
| 0〜2歳 | 選べない。毎日は自動で進む（育てる人の予約で決まる） |
| 3〜5歳（自我の芽） | 「遊ぶ」「休む」の2つから選べる |
| 6〜12歳 | 「啓発（学ぶ）」が増える |
| 13歳〜 | 「稼ぐ」が増え、お金を持てる |
| 18歳〜 | すべての行動、店を開く・生産する |

### 行動の予約
- 1日を「朝・昼・夜」の3枠に分け、それぞれに行動を1つ予約する。
- 結果はルールで計算する（AIの文章生成は使わない）。
  - 稼ぐ：R が減り、お金が増える。
  - 休む：R が戻る。
  - 啓発：B が減り、スキルが育つ。
  - 遊ぶ：B が戻る。

### 経済の回り方
- お金0 → 稼ぐ → モールで買う → 誰かの収入になる → その人が生産する、の一周。
- 生産とマーケットは records/production_rules_v0_22_1.md のルールに従う。
