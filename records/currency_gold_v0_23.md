# モールの通貨と課金通貨「ゴールド」（v0.23, 2026-10-25）

## ひびきさんが決めたこと
- モールの基本の通貨は SUNA にする。
- 課金の通貨として「ゴールド」を足す。
- 課金とゴールドは、自由な為替のもとで動く。
- 課金の単位は、本物の金（ゴールド）1g あたり、などにする。
- ユーザーは、最初にログインしたときお金が0（records/game_core_v0_23.md）。

## いまのサイト（試作）
- モールの値段は SUNA で表示し、横に二水の値段（文）を小さく出す。二水では 1 SUNA＝1,200文。
- 所持金は 0 SUNA から。「1時間はたらく」で +1 SUNA、1日8時間まで。
- ゴールドは 0 のまま。課金は準備中で、実際のお金は使わない。
- 保存のキーは triathlon-mall-v4。前の試作で持っていたお金と品物は引きつがない。

## Claude の案（仮）
| 項目 | 案 |
|---|---|
| 1ゴールドの価値 | 本物の金 1g の値段に合わせる |
| ゴールドと SUNA | 交換所で、売りたい人と買いたい人の数でレートが決まる（固定しない） |
| ゴールドで買えるもの | まだ決めない（一点物市場の品、見た目の品など） |

## まだ決めていないこと
- ゴールドで買える品物と、SUNA で買える品物の分け方。
- 金の値段をどこから取るか、どのくらいの間隔で直すか。
- 本物のお金を使う課金は、国ごとの法律（お金の決まり、ゲームの課金の決まり）を確かめてから作る。
