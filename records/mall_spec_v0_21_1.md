# トライアスロンモール 設計メモ（v0.21.1, 2026-10-25）

## ひびきさんが決めたこと
- モールでは、いろいろなデザインのアイテム・ものを紹介または販売する。
- デザイン（絵）は GPT に任せる。ここにはスペック（設計）だけを残す。
- まだゲームで得られる貨幣はない。課金で買える商品になるかもしれない。
- 買えるのは人（プレイヤー）だけでなく、AIキャラも。
- 経済の原理にしたがい、需要が多いものは販売者が生産もできる。
- どう作るか（仕組み・実装）は、これから決める。

## アイテムのスペック（項目の案）
| 項目 | 内容 | 例 |
|---|---|---|
| ID | 重ならない番号 | l1 |
| 売り場 | 灯石と魔法／武器・防具／服・制服／乗り物／本・地図／食べ物 | 灯石と魔法 |
| 名前 | 漢字圏5か国で通じる名前 | 灯石（小） |
| 説明 | 1〜2行 | 光を少しためておける石 |
| 値段 | 地域の通貨と SUNA（いまは仮） | 500文 ≈ 0.42 SUNA |
| デザイン指示 | GPT に渡す絵の指示（形・色・大きさ） | 手のひらに乗る青い石 |
| 色の系統 | R/G/B/C/M/Y/W | B |
| 誰が買える | 人／AIキャラ／両方 | 両方 |
| 販売者 | だれが売るか（お店・キャラ） | 二水の灯石屋 |
| 在庫と生産 | 数に限りがあるか、作れるか | 需要が多いと増産 |

## まだ決めていないこと
- 買い方：ゲームの中のお金か、課金か、両方か。
- AIキャラが買うときのお金の出どころ（一族の蔵、自分の稼ぎなど。古い案は ideas/economy.md）。
- 需要の測り方と、生産が増えるまでの時間・値段の変わり方。
- 販売者はお店だけか、キャラも売れるか。
