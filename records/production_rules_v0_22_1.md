# 生産とマーケットのルール（案） v0.22.1, 2026-10-25

## ひびきさんが決めたこと
- ゲームの構造を作る。AIが勝手にアイテムを作るのではなく、ルールに基づいて生産する。
- 人とAIがともに遊ぶ。公平さも大事だが、互いに得意な分野があるので特化できるようにする。マーケットを分けるかも考える。
- 例：AIには解けない問題を、人が解く。
- ゲームの形を複雑にしない（トークンがかかりすぎるため）。

## 1. 生産のルール（Claude の案）
AIは考えて作るのではなく、決まった表（レシピ）を計算するだけ。計算はプログラムで行い、AIの文章生成は使わない（トークンを使わない）。

| 項目 | 中身 |
|---|---|
| レシピ | アイテムごとに「材料」「作業時間」「必要なスキル」を1行で決める |
| 作れる条件 | スキルが足りていて、材料があるときだけ |
| 1回で作れる数 | レシピで決めた数（例：焼き魚は1回で5つ） |
| 需要での増産 | 注文の数が在庫より多いとき、1日に1回だけ増産できる |
| 値段 | 作業時間 × その地域の1時間の賃金 ＋ 材料費。需要で1日に最大±10%まで動く |
| 新しいアイテム | 人がデザインを出し、管理者が認めたときだけレシピになる。AIは新しいアイテムを作れない |

## 2. 人とAIの得意分野（案）
| | 人 | AI |
|---|---|---|
| 得意 | 新しいデザイン、好み・センスの判断、AIに解けない問題 | くり返しの生産、計算、たくさん同じ物を作る |
| 主な仕事 | 一点物を作る、依頼を解く | 量産品を作る、運ぶ、売る |

## 3. マーケットの分け方（案：まず2つ＋依頼板）
| 市場 | 売る人 | 買える人 | 中身 |
|---|---|---|---|
| 量産市場 | 人もAIも | 人もAIも | レシピのある品（食べ物・灯石・服など） |
| 一点物市場 | 人だけ | 人もAIも | 人がデザインした、数の少ない品 |
| 依頼板 | 依頼を出すのはAI（人も可） | 解くのは人 | AIに解けない問題。解くと報酬 |

## 4. まだ決めていないこと
- 報酬と買い方のお金（ゲームのお金か課金か）。
- 依頼板の問題の種類（絵の選択、なぞ、好みの判断など）。
- 1日の長さと、増産の回数の上限。
