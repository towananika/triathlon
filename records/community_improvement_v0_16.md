# TRIATHLON v0.16 - 社会を変えながら暮らす試作

更新日: 2026-10-25

## 実装したこと

従来の移住・日々の行動に、本人の学びと共同活動を追加した軽いルール式モデル。
ローカルAIのインストール・モデル導入・推論は再開していない。生成AIではなく、明示した条件で判断する成人の仮住民6人。

- 本人の学び: 60日目以降、同じ活動を20回試すごとに工夫を身につける。各分野0〜10の仮指標。
- 提案: 90日目以降、月ごとに生活充足が72未満なら、希望と実感の差から改善案を探す。
- 共同活動: 練習、交流、静かな庭、学習室、生活支援の5種類。
- 参加: 同じ地域で、不利益がなく、参加の余力がある2人以上。参加を強制しない。
- 他者への影響: 地域の誰かに、希望の重みから計算した不利益が出る案は見送る。
- 資源: 各地域12から開始。計画には4を使い、毎年2だけ補充。仮の敷地枠は各地域3。
- 作業: 週ごとに参加者が少しずつ進め、完了すると地域の条件が変わる。
- 副作用: 利点だけでなく静けさ等の低下も記録する。施設数・生活充足が無制限に増え続けるものにはしない。

この参加・合意ルールは共有活動の試作で、R帝国・G共和制・Bの各勢力の政治制度を一律に変更するものではない。
土地・資源・技術の本格的なシミュレーションではなく、制約を試すための仮定。

## 10年の標準条件比較

1年365日、合計3,650日。従来方式と「共同活動＋個人の学び」を追加した方式を同じ初期条件で実行した。
日々の波を避けるため、下表は10年目の365日平均。指標はモデル内の生活充足で、現実の幸福度ではない。

| 仮住民 | 従来 | 共同活動＋学び |
| --- | ---: | ---: |
| A | 78.7 | 92.0 |
| B | 79.5 | 89.2 |
| C | 78.6 | 89.4 |
| D | 79.1 | 89.0 |
| E | 54.3 | 91.6 |
| F | 77.9 | 78.7 |

Gで仮住民BとEが協力し、生活支援拠点（119日目）、挑戦・練習スペース（154日目）、静かな庭（210日目）が完成。
共同学習室は他の住民への不利益、交流スペースは敷地不足で見送り。
参加者不足の提案もあり、RやBが同じように施設を作ったとはしていない。

個人の学びも同時に導入したため、数値の改善を共同施設だけの効果とは言えない。最後の1日ではFが従来80・新版74となるが、年間平均では77.9・78.7。単日の上下だけで良し悪しを断定しない。

人口は両方式ともR1人・G2人・B3人。施設の増加は最初の1年で止まり、その後は再び安定する。
目標の大きな変化、人口増加、加齢・出生・人間関係の成長、本格的な経済・制度変更は未実装。今後の課題として残る。

## 保存と再現

- 従来の保存を引き継ぎ、その日以降に新しい学び・共同活動を適用する。過去を勝手に再計算しない。
- 「10年まで」で現在の条件のまま上限まで進められる。
- 「標準条件の10年比較」は現在のスライダー操作とは別の固定条件の参考結果。
- `node generate-community-report.cjs` で比較JSONとブラウザ用データを再生成できる。
