# 二水を3Dで歩く — 体験仕様（段階2）

## 一行の意図

ななめ上から見下ろす小さな二水を自分のキャラで歩き、近づいた住人と話すと、2Dと同じ一日の記録が残る。

## この版でできること

- 二水のひと区画（川・朝市・図書館の3つの場所と住人）を3Dで見る。視点はななめ上から見下ろす（96-2）。
- 地面をタップ（クリック）するか、矢印キー／WASDで歩く。
- 住人に近づくと「話す」が出る。押すと2Dと同じ3つの選択肢。
- 計算は `play/day-one/engine.js` と `content.js` をそのまま使う。保存も2Dと同じ（同じ人生の続き）。

## この版で約束しないこと

- 足あと・ほかの人の一言（段階3、Firestore）。
- キャラや建物の絵（今は形と色だけ）。

## 完了条件

1. 初回に「ランダムな人生を受け取る」が出て、押すと3Dの町と自分のキャラが出る。
2. 歩いて住人の近く（2m以内）に行くと「話す」が出る。遠いと出ない。
3. 3回話すと、その日の終わりと「次の日へ」が出る。
4. 2日目に前日の住人へ近づくと、前日への一言が出る。
5. 歩く計算は `node play/nisui-3d/move.test.cjs`、スマホ画面は `node play/nisui-3d/screen.check.cjs` で検証できる。
