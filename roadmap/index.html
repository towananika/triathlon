現在のタスク制作の進め方長期計画

現在の重点 / BG-01

暮らしの異なる、三つの背景

市場の裏路地 → 朝の渡し場 → 図書館。背景の制作をまとめて進め、各画像の確認は一枚ずつ行います。人物・物語・サイトの作業は別タスクに分けます。

  • 背景案は12場面を整理済み
  • 電停の見本は1枚生成し、好評価
  • 次の3地点はまだ未制作

見本への好評価と、正史・地図・サイトへの採用は別です。生成済みだけで完成や公開とは扱いません。

タスクと完了条件

各項目を開くと、成果物・完了条件・依存関係を確認できます。数値の進捗率は、測れる基準がないため表示しません。

  1. PLAN-01世界観と場所の設計企画保存済み
    成果物
    人と行き交う場所・誰かと暮らす場所・自分に戻れる場所の3群、計12場面の企画。各場所を人物の日常と結び付けます。
    完了条件
    誰が何のために使うか、自然と街の関係、そこで生まれる気持ちが説明できること。既存の場所と新しい提案を区別すること。
    残る確認
    本編の年代、地図上の位置、学校・交通との接続。クラスと国籍、二水の地区と国家を同一視しません。
    次への引き渡し
    背景を描くための仕様は整理済み。未確定の地理や歴史は、見本の設定で上書きしません。
  2. BG-01日常背景3地点次の制作
    1. 市場の裏路地・昼未制作。軒の影、洗濯物、台車、片付けの痕跡。買う人だけでなく、働く人の時間を感じられる場所。
    2. 朝の渡し場未制作。朝もや、水位の跡、桟橋と対岸の距離。移動と朝の光を描きます。
    3. 図書館の天窓・夜未制作。使い込まれた机、本、空と読書灯。静かな室内と一人の時間を描きます。
    成果物
    人物なしの背景3枚と、構図・光源・人物を置ける位置の制作メモ。
    完了条件
    現実感と作画が合うこと。建物・移動経路・遠近・光が自然で、3地点の用途と雰囲気が異なること。ユーザー確認を経て採否を記録します。
    作らないもの
    全12地点、全季節・全天気差分、追加人物、動画を一括で作りません。生成画像を交通・建築の工学的な検証済み資料とも扱いません。
    次への引き渡し
    採用背景だけを人物の姿勢・影合わせに渡します。修正が必要なら、その一枚の修正を先にします。
  3. CHAR-01人物らしさと姿勢見本の確認待ち
    現在あるもの
    採用済みの人物の外見参照と、三人が夕方のベンチで休む場面の生成見本。後者の採用は未確定です。
    成果物
    ファイター・ナイト・ウォーリアの、待つ・疲れる・休むなど必要な姿勢差分。髪・顔・服・持ち物の同一性を保ちます。
    完了条件
    顔だけでなく姿勢や振る舞いでも別人に見えること。同じポーズを並べず、手足・小物・年齢・衣装を確認。透過素材は実際のアルファも確認します。
    前提
    置く背景と場面を選んでから必要な差分だけ制作。背景と合わせた光・接地・影の確認までを含めます。
  4. STORY-01日常の短編を一本に台本案あり
    現在あるもの
    帰り道、疲れを言葉にする、少し休む、という3場面の台本・絵コンテ案。
    成果物
    場面順・短い台詞・主要な絵を揃えた短編1本。人物と背景から気持ちが伝わる形にします。
    完了条件
    三人の違いが分かり、最後まで無理なく読めること。頑張りだけでなく疲れも受け止め、説教や報酬だけの結末にしないこと。
    前提
    既存本編の原稿と年代・学校・場所を照合します。原稿の確認なしに公開済みの話数へ割り込ませません。
  5. WEB-01採用素材の掲載素材の採用待ち
    成果物
    採用画像を既存の人物・物語ページなどへ掲載。用途に合う画像サイズ、説明文、読み込み方法を整えます。
    完了条件
    スマホ・PC、公式版の明暗、画像の読み込み、文章の収まり、戻る導線を確認。権限が必要な導線は一般ユーザーへ表示しないこと。
    前提
    画像と内容の採用、公開範囲、参照素材の権利を確認します。ローカルにあるだけの制作資料を一括公開しません。
    別途検討
    ホーム全体を一枚のつながるストーリーラインにする案。まず短い場面の掲載を確認し、全面改修の費用対効果を判断します。
  6. GAME-01短い探索と自動戦闘後続の試作
    決まっている中心
    一人を選ぶ → 短い探索・自動戦闘 → 報酬を一つ選ぶ → 帰る。既存の五人小隊戦とは分けて扱います。
    成果物
    一つの探索場所を一巡できる試作。旧観測所は候補であり、敵・所在地・時間配分は未確定です。
    完了条件
    初見でも目的と操作が分かり、一巡後に何を持ち帰ったか確認できること。途中帰還や敗北時の扱いを選択前に示し、保存・再開を検証します。
    再開時の確認
    既存の戦闘と未公開変更を確認し、使える部分と新規範囲を分けます。世界全体の完成やオンライン運営開始とは区別します。

響の資料読取・教材化ツールは別プロジェクトで管理し、このゲームの制作完了には数えません。

制作の進め方

  1. 仕様を揃える目的・参照・必要な枚数・完了条件を決める。
  2. 同じ種類をまとめて作るまず背景。制作中に別の機能開発を混ぜない。
  3. 一枚ずつ確認する生成済み・好評価・採用確定・公開済みを分ける。
  4. 採用分だけ掲載・検証する必要な箇所へ絞って反映し、変更内容をお知らせに残す。
延期・見直しの基準

原稿・年代・地形と矛盾する場合は、生成や掲載より整合確認を先にします。工数・表示の重さ・費用が増える場合は、枚数や差分を減らします。見本が好みに合わなければ量産せず、その一枚で方向を直します。画像・映像の利用枠を正確に把握しているとは扱いません。

UI・文・資料の追記はマイナー更新。新モードや大型章など、ゲーム内容のまとまった拡張があるときだけメジャー更新とします。版番号の基準を見る

変えない中心

  • 世界観と物語を先に。人物の望みと、関係の変化を大切にする。
  • ウェブでは絵が主役。音は、ビジュアルの基準が整ってから。
  • 戦闘のコアは自動戦闘。長時間の反復や毎日の参加を強制しない。

また来たくなる、美しい日常へ

最初に届けたいのは、東アジアの日常に親しみがあり、人物や物語に惹かれる人。これは初期の仮説で、年齢や国籍で閲覧を限定するものではありません。

見覚えのある電停、路地、窓辺を入口に、光・空・水を美しく描きます。手入れや使い込まれた跡、疲れて休む時間も残すことで、遠い理想郷ではなく「ここで過ごしてみたい」と感じられる世界を目指します。

魅力を確かめる三つの問い
  1. 短く見ただけで、行ってみたい場所を一つ選べるか。
  2. 説明文だけに頼らず、また会いたい人物が一人見つかるか。
  3. 続きの場面や、別の時間帯の景色を見たいと思えるか。

公開前の見本と公開後の反応で確認する予定です。検証人数や結果はまだありません。見た目の変更だけで再訪が増えるとは断定せず、読み込みの軽さやスマホでの読みやすさも同時に確かめます。

長期計画

各段階は、前段階の完了条件を満たしてから広げます。期間内にすべてを実装する約束ではありません。

  1. 01

    まず半年以内 / 現在の重点

    九人と、最初の景色

    企画・試作

    人物の違いが絵で伝わり、短い物語と戦闘を一巡できる形へ。

    • 採用済みの立ち絵を基準に、顔・体格・姿勢・服装の一貫性を整える。
    • 出発・意見の分かれる場面・帰り道の絵コンテを作る。
    • 短い探索、自動戦闘、報酬、帰還をつなぐ。
    詳細企画と確認すること

    物語・ビジュアル

    光の章はファイター・ナイト・ウォーリアを中心に。まず一場面で表情と立ち位置を検証し、キャラの透明素材と人物なし背景を分けて用意します。完成場面では光と影、遠近を合わせます。

    日常の景色

    日本・韓国・中国の現実にある美しさを背景の参考にします。電車の中、駅を出た交差点、小さな駅から家までの道など、見覚えのある場所を入口に。建物・看板・舗装・車内の違いを残し、自然光、水の反射、雲の奥行き、澄んだ空で魅力を引き出します。背景の参考と、採用済みのキャラ作画は分けて扱います。

    自然と都会、その中で暮らす人

    遠い理想郷だけではなく、東アジアで暮らす人が自分の日常と重ねられる場面を大切にします。頑張る姿と同じように、帰りの電車で疲れて黙る、寄り道する、家で一息つく姿も描きます。疲れや弱さを必ず成功に変えず、そのまま受け止められる物語を目指します。

    小さく作って、繰り返し使う

    最初は少数の共通背景を優先し、構図を保って朝・昼・夕方の光を変えます。人物を別素材にすることで場面を増やし、毎回の新規生成や大きな動画制作を避けます。動きは必要な場面だけに絞り、静止画でも物語が伝わることを先に確かめます。

    小さなゲーム

    一人を選び、短く探索して自動戦闘を体験。報酬を一つ選んで帰還する試作を企画しています。街はずれの旧観測所が候補です。敵、所在地、時間配分は未確定です。

    次へ進む条件

    初めての人が迷わず一巡でき、キャラごとの違いが伝わること。スマホで表示・保存・再開を検証し、既存の物語と年代の矛盾を解消してから範囲を広げます。

  2. 02

    半年〜1年程度 / 前段階の検証後

    また会いたくなる、小さな世界

    計画

    同じ場所でも、人物・道・目的によって違う時間が生まれる体験へ。

    • 前に過ごした時間が、会話や振る舞いに残る。
    • 同行していないキャラにも、それぞれの用事で出会える。
    • 装備、部屋、思い出など、持ち帰った成果を楽しめる。
    詳細企画と確認すること

    人物との再会

    同じ会話の回収を義務にせず、好きな一人と過ごしても、一度だけ訪れても成立させます。断る・休む・一人で過ごす選択も残します。

    暮らしと成長

    持ち物を使う、飾る、少し変える範囲から制作を検証します。複雑な生活費や大量の職業を一度に追加しません。

    作る単位と順番

    まず再会で会話が変わる小さな分岐を一つ検証し、その後に持ち帰った品を部屋へ置く体験をつなぎます。同じ場所の時間・天気差分を再利用し、場所の数だけを増やしません。生活シミュレーション全体を先に完成させる必要はありません。

    残す成果物

    再会の分岐表、人物ごとの記憶の範囲、部屋で使える小物の仕様、保存データの移行テスト。本人の選択や同意を飛ばして、関係や住まいが勝手に変わらないことも確認します。

    次へ進む条件

    報酬のためだけでなく、再会や探索自体が楽しめること。長時間の周回が必要になっていないか、保存データを安全に更新できるかを確かめます。

  3. 03

    1〜3年 / 運営の見通しが立った場合

    一人の時間が、街につながる

    構想

    同時に遊ばなくても、各自の探索や制作が街へ届く仕組みを検討。

    • 街の整備への任意参加から、非同期の協力を検証する。
    • 地域と物語を少しずつ広げ、社会の変化をニュースで伝える。
    • 運営・安全・費用を確認してから、少人数の同時協力へ進む。
    詳細企画と確認すること

    オンラインの入口

    共有報酬はサーバー側で検証します。公式版と開発版の切り替えや画面の非表示を、認証の代わりにはしません。現在の試作がオンライン運営済みという意味ではありません。

    参加の自由

    街への貢献、対戦、売買を必須にしない設計を検証。個人の時間と共有世界の時間をどう両立させるかは未解決の課題です。

    作る単位と順番

    最初は一つの共同整備をサーバー側に記録し、別の利用者にも反映される非同期の試作から。認証・権限・重複操作・復旧を確認してから、少人数で同じ場面に入る実験へ進みます。自由取引、共有経済、国家戦争を一括で追加しません。

    残す成果物

    共有する情報と個人情報の区分、権限と不正対策の試験、バックアップからの復旧手順、通報・運営手順、利用規模ごとの費用見積もり。公開範囲を広げる前に、継続できる人数と負担を確認します。

    次へ進む条件

    不正対策、データ復旧、通報対応、サーバー費用と制作負担を継続して支えられること。自由取引や国家戦争を先に始めません。

  4. 04

    3年以上 / 長期の方向性

    世代をこえて、生きる世界へ

    長期構想

    暮らしと創作、社会の変化を、人物の人生として見守れる世界へ。

    • 世代交代、家族、継承と、色の章以降の人物を段階的に描く。
    • ユーザーの都市計画と、住民の望みが影響し合う体験を検討する。
    • 動く景色と短編映像へ。音楽、2.5D、3Dも、制作可能性を確認して選ぶ。
    詳細企画と確認すること

    長い時間

    人物の記録を年代別に分け、世代が変わっても同一人物と混同しないようにします。家族や継承を全プレイヤーの必須目標にはしません。

    作りたいものを作る

    家具・服・道具から、家や街へ。地球の地形・気候・資源を土台にしますが、遊びと制作の負担を見て単純化します。

    動く映像への夢

    まず人物なし背景と透明なキャラ素材を整え、水面・雲・光などの小さな動きから、人物が暮らす短い映像へ進むことを目指します。静止画を再利用し、光と影の整合性を大切にします。動画制作の開始時期・方式・費用は未定で、有料生成や参考動画の転載を決めたものではありません。

    広げる分野は分けて試す

    世代交代は人物と年代の記録を引き継ぐ試作、創作は家具など一品から家・街への段階、映像は背景の限定的な動きから短い場面へ。それぞれ別に検証し、全分野が揃わないと遊べない設計にはしません。

    残す成果物

    世代と人物を混同しない記録方式、地形・気候・資源を反映した制作ルール、素材の再利用と光・影の基準、映像や3Dの端末負荷と制作費の検証記録。長い人生を描く際も、本人の望みとユーザーの操作範囲を区別します。

    実現の判断

    規模を大きくすること自体を目的にせず、人と世界の魅力が増すかで判断します。すべての構想を実装する約束ではありません。

次の一件

市場の裏路地を人物なしで一枚作り、街の生活感・光と影・人物を置ける余地を確認する。確認後、朝の渡し場と図書館へ進みます。
