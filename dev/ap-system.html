未決定事項

✅ W → 隠れスタットに決定（2026-11-07）

Wはプレイヤーや他キャラには見えない隠れスタット。誕生時に45APをRGBWに配分するが、WはUI上には表示されない。ゲームの挙動（判定・乱数・特殊発動など）に裏で影響する設計。

✅ 発揮率の計算 → 先天的最大値を100%とする比例（2026-11-07 更新）

発揮率 = 今の生殖能力 ÷ 自分の先天的最大値。自分のピーク時が100%。生殖能力0のキャラはスタット一生1（例外）。
各スタット実値 ＝ max(1, AP × 発揮率)

✅ 0〜2歳のAP配分 → ランダム（2026-11-07）

自我が生まれる前（0〜2歳）は、毎月のAP配分もランダムに行われる。

✅ Wの機能 → 今はなし（2026-11-07）

W（隠れスタット）は数値として誕生時から存在するが、現時点では何にも効かない。後で機能を足す。

✅ 発揮率モデル → 先天的最大値を100%とする（2026-11-07）

発揮率 = 今の生殖能力 ÷ 自分の先天的最大値

どのキャラも自分のいちばん良い時期が100%になる。生まれつきの高低は強さに直結せず、年齢による上がり下がりだけが効く。

個人差は「時期」でつける：思春期の始まり・ピークの長さ・下がり始める年齢を、平均から数年ずらす。

✅ 先天的生殖能力0のキャラ → スタット常に1（2026-11-07）

生まれつき生殖能力が0のキャラは、スタットは一生 1 のまま（例外扱い）。

APから戦闘数値へ（式）

ステップ1：発揮率（年齢で変わる）

発揮率 = 今の生殖能力 ÷ 自分の先天的最大値
（生殖能力0のキャラは例外：スタット = 1）

ステップ2：働くAP（色ごと）

働くR = max(1, R_AP × 発揮率)
働くG = max(1, G_AP × 発揮率)
働くB = max(1, B_AP × 発揮率)

ステップ3：戦闘スタット = 働くAP × クラス重み × 変換係数

HP・ATK・DEF ← 働くR × クラスのR重み
RAN・ATS・SPD ← 働くG × クラスのG重み
INT or MAG・RES・MP ← 働くB × クラスのB重み
※BのAPはINTかMAGのどちらかを毎月選んで上げる。MAGはスキルでも増える

✅ INT と MAG は同一スタット・クラスで表示名が変わる（2026-11-07）

中身は1つのスタット。RとGクラスには「INT」、Bクラスには「MAG」と表示される。

INT（知能）：武器の使用条件・戦闘戦略に効く。MAG（魔力）：魔法ダメージに効く。どちらも同じ値から来る。

誕生時AP：R・G・B・Wの4つに各最小6。W（隠れ）はMAGとは別。

✅ Bクラスを3つに整理（2026-11-07）

エレメンタルメージ / メージ / クレリック（ナクシャを外す）

クレリック（クレリス宣教学校）のサポート系魔法スキル：

  • 定型魔法陣：事前に描いた魔法陣を起動する（準備型・範囲）
  • 治癒祈祷：味方のHPを回復する
  • 守護祈祷：味方のDEF・RESを一時的に上げる
  • 加速祈祷：味方のSPDを上げる
  • 浄化祈祷：状態異常を取り除く
  • 支援維持：複数のバフを同時に保ち続ける（持続コスト↑）
