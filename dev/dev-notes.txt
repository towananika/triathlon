## 0. ひとことで
- **九つの光が、一生をかけて灯る町。**（副題「九つの光の、一生」）
- 軸は **世界観と物語**。戦いはその中の一場面にすぎない。
- いちばんの芯は「一人の一生をまるごと見守る」こと。年齢で変わる悩みを、性のことも含めて正直に描く（成人向けにはしない。未成年は性的に描かず、心の成長だけを描く）。
- 読者として思い描くのは 30〜50代。地域は日本・韓国・台湾・香港・マカオ・中国・ベトナム。参考にする作品は「セックス・エデュケーション」「インサイド・ヘッド2」とウェブトゥーン。
- 今の進め方：一般向けの公開は形になってから。ゲームは開発ページ（dev/、管理者だけ）で試作する。

| 年表 | 新暦の年表は、別のシミュで生まれた「過去の結果の一つ」として参考にする。どの世界でも同じ歴史にはしない | 決定（8-2） |

- 舞台の町は **二水市**。二つの川が出会う町で、渡し舟・路面電車・川守隊（町の守備隊）がある。二水学園の高等部が物語の中心になる。
- 謎は4段階で深まっていく（言い切らない）。
  1. 第1期「層がある」：川底から、新暦より古い灯石の層が見つかる
  2. 第2期「層は人が作った」：通路と眠りの部屋がある。空の寝台が百ある
  3. 第3期「声と層はつながっている」：声は層を通って町に届いていた。光のない耳にだけはっきり聞こえる
  4. 第4期「答えに触れる」：「ここから、もう一度」。それでも言い切らない

## 2. 魔法
- 正体：AIが作った、人間には解明できない「エネルギーの元」。それを使うと魔法になる。ファンタジーではない（5-4）。
- 人間もAIも使える。使い方は違うが、その中身は保留（7-1）。参考：人間は灯石（手のひらのAI道具）と詠唱で使い、AIは直接使う。
- 形は2つ。線形魔法は一列に詠唱する。円形魔法は途中で切れても効く。
- 第1期（新暦312年）の灯石と「AIの魔法は450年ごろから」という食い違いは、8-2 で解けた。年表は過去の結果の一つにすぎず、固定しない。

## 3. 物語（4つの期・新暦312〜381年）
各期は高等部の3年間で、3部と終章がある。分かれ道は3つ。恋は「芽」まで描き、誰と結ばれるかは本人が選ぶ。

| 期 | 年 | 題 | 色 | あらすじ |
|---|---|---|---|---|
| 第1期 | 312〜315 | ふたつの川、九つの光 | R/G/B | 9人が川辺の古い「灯台館」を直す実習で出会う。3年で町と自分の答えを選ぶ。39場面・結末8通り |
| 第2期 | 334〜337 | 層の向こう | C/M/Y（親の光の混ざり） | 9人の子どもたち。灯台館の床下の扉を開け、層が人の手で作られたことを知る |
| 第3期 | 356〜359 | 白と黒の市場 | 白/黒/灰 | 魔法を使えない子が増えた時代。6人が市場で生き方を選ぶ |
| 第4期 | 378〜381 | 白紙の地図 | 空（エンプティ） | 学年で二人だけの「空」の子、ハナとアユム。4世代分の手がかりを持って、地図の外へ最初の道を描きに行く |

- 第1期の分かれ道（A/B）
  - ① 灯台館を自分たちの場所にするか
  - ② 大橋の計画に関わるか：設計に加わるか、川辺を守る運動をするか
  - ③ 眠りの層をどうするか
  - 3つの組み合わせで、10年後の二水市が8通りに分かれる。第2期の始まり方も変わる。
- 大人の登場人物（30〜50代の読者が自分を重ねられるように・10/26 承認）
  - サナエ（42）：アカリの母、豆腐屋
  - 九条ソウマ（48）：シオンの父
  - チカ先生（39）：学園の図書館
  - 船頭マツ（61）
  - 第6話から各話の終わりに大人の場面を入れる。第8話からは大人が語り手の回も入る。
- 公開しているのは第1期だけ。第2〜4期は開発用（共有フォルダの story/saga.html）。

## 5. ゲームの形
| 項目 | 内容 |
|---|---|
| 最初に遊べるもの | 見回り ＋ 文明シミュ の2つ。今は別々の試作で、あとでつなぐ（8-5） |
| プレイヤー | 最初は一人のキャラを動かす。地位や役割でリーダーになれば、**自分が長の集まり全体**を動かせる（8-3） |
| 動かし方 | キャラは、ユーザーかAIがコントロールする。または「声」（助言・準備・ねぎらい）で影響する。従うかは性格や絆しだい |
| AI の判断 | AIは**キャラ本人の幸せ**をいちばんに考える。性格・好み・関係も反映する（8-4） |
| キャラの頭 | 本物のAIは使わず、決まったきまりで動く（トークンを使わない）。差し替え口は1か所 |
| 規模 | 数千人以上。見ている所だけ細かく計算し、遠くは集団として粗く計算する |
| 時間 | 升目の地図の上で流れる。留守の間は止まり、戻ったときにきまりで計算して追いつく |
| 勝敗 | 関係・士気・消耗で終わる。全滅するまで戦わなくてよい（5-3） |
| 外交 | 性格・関係・実績で自動的に決まる（5-5） |
| 資源 | 使うと減る。管理・回復・技術で増やせる（6-2） |
| 死と継承 | 戦いや事故で死ぬこともあるので、備えと選択が大事（4-4）。継承は組織や文化のきまりで、長子・実力・投票のどれか（4-5） |
| 物語の終わり | 固定せず、遊びながら決める。終わっても新しい世代が引き継ぐ |
| 基準 | スタークラフト（地図・生産・三つの違い・資源の緊張）。操作の速さは借りない |
| 方針 | ゲームはシンプルにする。複雑な関係・うわさ・選択肢は物語の側に任せる |

## 6. 見回り（核）— dev/patrol.html
- 流れ
  1. 物語の前の文
  2. 3人で見回り
  3. 自動の戦闘
  4. 結果を文章で読む
  5. 物語の後の文
- 準備は数に限りがあるので、選ぶことに重みが出る。声は聞かれないこともある。
- バランスを確かめるための自動試行がある。チーム戦の勝率は 47〜53% に収める（dev/squad.html）。

### 今の見回り（v0.8・11/8。PCで作っている：https://claude.ai/artifact/5uUyZ8KqhyLfpJXeGq8khV）
- 1日の流れ：詰所（ホーム）→ 休み時間（1日1回、だれと過ごすか選ぶ）→ 見回り3回 → 詰所に帰る。見回り1日＝ゲームの1か月
- 詰所：選んだ子が大きく立ち、さわると一言。ボタンは「休み時間／見回りへ／3人／思い出」だけ。スタミナ・お金・赤い点はなし
- 成長（11-4〜11-6）：毎月+5AP をプレイヤーが体・技・知に振る。「おまかせ」で性格どおりに自動。振り直しなし。振る前に見通しを薄く見せる。Lv はなし。育てた力が効いた場面を結果に一文で出す
- ここぞの技（11-7）：ゲージ6で光るボタン、1戦1人1回。アカリ「れんげき」／ツバサ「しびれる一撃」／シオン「みんなを守る」
- 3人の画面：立ち絵・プロフィール・体技知のバー・AP・技。思い出：読んだ場面がたまる
- まだ決めた形と合っていないところ（再開したら直す）：休み時間で強さが上がる（→調子だけに）、帰り道のできごとと夜のねぎらいがない、「最初から育て直す」ボタン、振る前の見通し、AP が戦いごと（→月+5AP）

## 7. 文明シミュ — dev/civ.html（画面）＋ dev/civ-sim.js（計算）
- キャラ1人1人から始まり、人数で段階が上がる。
  - 群れ：20人未満
  - 村：80人未満
  - 町：300人未満
  - 国：300人以上
- 一生の流れ：生まれる → 年をとる → 相手を見つけて子が生まれる（生殖能力の表 TRI_FERT を使う） → 亡くなる。
- 集まりが60人以上になると分かれる。
- 長の決め方はその集まりのきまりで、長子・実力・投票のどれか。
- 一人ずつに次の3つを設定できる。
  - 動かす人：自動／ユーザー／AI
  - 力を入れること：手入れ・畑・遠くを見る・話す・学ぶ
  - 声
- 季節で実りが変わる。月ごとの倍率は 冬0.4 → 春1 → 夏1.2 → 秋1.4。
- 年に一度のできごと：豊作・大雨・祭り・はやり病。
- 水路と道は月に0.4%ずつ古びる。手入れする人が直し、実りは水路と道の状態で変わる（0.7〜1.3倍）。手入れの費用は、ほかの使い道と取り合いになる。
- 見張りがまちがった知らせを出すと信頼が下がり、本物の知らせも無視されて事故になる。
- 外交と争いは自動で決まり、士気が尽きると終わる。
- 画面にあるもの
  - はじめての3行案内
  - 次の節目（例：町まで あと○人）
  - 節目だけの年表
  - 一生カード（年表と一緒にコピーして共有できる）
- 300年回しても安定することを確かめた。最初の24人から、約220人まで増える。

## 8. AP システム（からだと強さ）— dev/ap-system.html
- 生まれたとき、45AP を R・G・B・W に分ける。それぞれ最低6で、残りの21はランダム。
- 毎月 +5AP。配分は本人が決める（0〜2歳はランダム）。
- **発揮率 ＝ 今の生殖能力 ÷ 自分の生まれつきの最大値**。どのキャラも自分のピークが100%になる。
- **スタット ＝ max(1, AP × 発揮率)**。1より下にはならない。生まれつき生殖能力が0のキャラは、一生スタット1。
- 個人差は「時期」でつける。思春期が始まる年、ピークの長さ、下がり始める年を数年ずらす。
- 生殖能力は0〜100歳まで1歳ごとのデータがある（dev/fertility.js、ideas/fertility-by-age.csv）。
- 色とスタット
  - R：ATK・DEF・HP
  - G：RAN・ATS・SPD
  - B：INT（MAG）・RES・MP
  - W：隠れスタット。今は働きなし
- INT と MAG は同じ値。R・G のクラスでは INT、B のクラスでは MAG と表示する。
- 性別の補正
  - 男：HP×1.08、ATK×1.29、DEF×1.18
  - 女：HP×0.92、ATK×0.71、DEF×0.82
  - B クラスは ATK・DEF に補正がない
- クラス
  - R：ファイター／ナイト／ウォーリア
  - G：レンジャー／アサシン／スカウト
  - B：エレメンタルメージ／メージ／クレリック
- クレリックの支援6技：定型魔法陣・治癒祈祷・守護祈祷・加速祈祷・浄化祈祷・支援維持
- 三すくみ：R が G に、G が B に、B が R に強い（1.3倍、逆は0.77倍）。

## 9. マルチプレイの準備
- 世界は「種」と「行動の記録」で決まる。同じ種と同じ記録なら、同じ結果になる。
- 行動はすべて act() の1か所を通る。あとで Firestore に差し替えられる。
- 乱数の状態も保存している。「検算」ボタン（verify）で記録を最初から再生し、今の世界と一致するか確かめられる。
- キャラには持ち主（プレイヤーID）がある。
- オンラインは無料の範囲だけで、保存するのは声だけ。Firestore のルール追加は保留（案は dev-plan.md の末尾にある）。

## 10. 見た目と作り方のきまり
- 純白や純黒は使わない。背景も文字も、目に優しい自然系の色（生成り・墨茶・苔・藍・枯草）にする。site-theme.css に入っていて、記録は管理ページの「デザイン設定」にある。
- 文字は少なく、図・メーター・カードで見せる。日本語だけを使い、ハングルは使わない。
- 絵はひびきが作る（GPT）。Claude は文としくみを作る。
- AI で作るときのきまり（AGENTS.md）
  - 計算と画面を分ける
  - 機能ごとにファイルを分ける
  - ときどき片づける
  - あいまいなら理解を確かめる
  - 大きな変更は先に聞く
- 動画から学んだこと（youtube-notes.md）
  - 作ったものは古びる
  - 誤報が多いと警報が無視される
  - 早く作った所ほど古い設備に縛られる
