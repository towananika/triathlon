# 漢江ハイウェイ（ソウル高速ドライブ）開発メモ

ソウルの都市高速を一人称で走るブラウザゲーム。`index.html` 1ファイル（ライブラリなし、疑似3D）。
開発は **2026-11-14 に中止**。ここには中身だけを置いている（メニューからのリンクなし）。

## 状態
- 公開版（Claudeのアーティファクト 第4版）にあるもの：韓国販売トップ10＋大型・準中型・軽、輸入車10台、アバンテN、ナビ4種（独自の名前）、居眠り休憩所（眠気メーター）、仁川空港コースの料金所とハイパス、ランダム出発と地図で目的地選び、ルームミラー・サイドミラーと死角警告、購入時の仕様選び、給油とEV充電、オンライン（記録・チャット・ひとこと・走っている人）。
- このファイルにだけあるもの（未公開・未確認）：現在地から出発、龍山（江辺北路）コース、世界の名車9台、アカウント保存、タクシーモード（ソウルの中型タクシー料金）、グレード・パッケージとプレビュー、ドル表示。
  - 既知の不具合：仕様画面のプレビューが「クイック」のボタンに重なり、押せない。
- GitHub Pages では Claude の機能が使えないため、オンライン機能は動かない（一人で走るだけ）。

## 決まったこと（2026-11-14）
- 車は純正だけ。改造はあとで決める。
- 本物っぽい運転感と音を入れる。
- 仕事の種類、のんびり走れること、人と一緒に走ることは採用候補。
- 乗客の物語・会話は入れない。
- お金はドル基準（1ドル＝約1,400ウォン）。タクシーのメーターはウォンで動かす。

## あとでやること
- 景色を現実に近づける（各コースのランドマーク）。
- 車から降りて外から眺める、車内を見渡す（本物の3D表示が必要）。
- 駐車・後進の練習（駐車場モード：実寸と小回り、後方カメラとガイド線、障害物の音、上から見た図）。

## 調べたこと（ドライブゲームで好かれるもの）
車の改造と収集、運転感と音、仕事の種類、のんびり走れること、人と一緒に走ること。嫌われるのは繰り返し・目標がないこと・空っぽな地図。
